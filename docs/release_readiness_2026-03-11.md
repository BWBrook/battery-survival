# Release Readiness — 2026-03-11

## Scope
This note tracks release readiness for the workflow-level inconsistency between:
1. Standard manuscript renders under `outputs/manuscript/`
2. Production Bayesian artifacts generated by `just bayes-prod`

## Prior risk state
Before the additive review workflow, the repo had this inconsistency:
1. `just bayes-prod` produced valid production Bayesian artifacts.
2. `just full` / `just manuscript` rewrote the shared Bayesian output paths into disabled-state artifacts.
3. As a result, the standard manuscript could not simultaneously remain canonical and also reflect the production Bayesian review state.

## Chosen implementation
Accepted direction:
1. Keep the standard workflow unchanged.
2. Snapshot authoritative production Bayesian artifacts under `outputs/review/bayesian_snapshot/`.
3. Render a separate review manuscript under `outputs/review/manuscript/` using:
   - canonical non-Bayesian outputs from `outputs/`
   - production Bayesian snapshot inputs from `outputs/review/bayesian_snapshot/`

## Ready-for-review criteria
1. `just bayes-prod` writes the production Bayesian snapshot.
2. `just full` still works unchanged.
3. `just manuscript` still works unchanged.
4. `just manuscript-prod-bayes` renders a review manuscript whose Bayesian section matches the production snapshot.
5. `just review-prod-bayes` runs the end-to-end additive review workflow with real logs in `logs/`.
