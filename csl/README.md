# CSL directory

`author-date.csl` is a journal-neutral author-date/Harvard style copied from
the Citation Style Language styles repository:

- source: <https://github.com/citation-style-language/styles/blob/master/harvard-cite-them-right.csl>
- upstream style: `harvard-cite-them-right` (Cite Them Right, 12th edition)
- upstream style author: Patrick O'Brien
- upstream license: Creative Commons Attribution-ShareAlike 3.0
  (<https://creativecommons.org/licenses/by-sa/3.0/>), as stated in the CSL
  file's `<rights>` element
- source revision retrieved 2026-09-12; the file records the upstream
  metadata and update date

This is a provisional style for manuscript development. It does not imply a
journal choice. Replace it with the target journal's official CSL after the
venue is selected, and verify the rendered bibliography before submission.
